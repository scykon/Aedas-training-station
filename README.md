# 商业综合体平面设计 · 成长训练系统

> 使用者身份：商业综合体**立面设计师** → 目标：成为能独立操盘商业平面、对标 **Aedas（凯达环球）** 商业团队的复合型设计师。

## 最重要的两条规则

1. **只在周一~周五训练，周末全休。** 周末不推送任务、不出评价，安心休息。
2. **法定节假日停训，自动顺延。** 2026 年内会碰到中秋（9/25）与国庆（10/1–10/7），这 6 个工作日不计入训练日。

**日期安排**

| 阶段 | 日期 | 说明 |
|---|---|---|
| **预备周** | 2026-09-16（三）~ 09-18（五） | 3 天热身：读体系、备工具、定锚点。不计入 12 周 |
| **12 周训练** | 2026-09-21（一）~ **2026-12-21（一）** | 共 **60 个训练日**（= 12 周 × 5 天） |

> 注意：本计划里的「一周」= **5 个训练日**，不等于自然周。中间隔了国庆长假，所以从第 2 周起周次会和日历错位——**一切以 `04-训练日历.md` 的逐日表为准**。

## 每日循环（仅周一~周五）

```
上午 10:00  推送今日任务包（阅读材料 + 抄绘任务 + 自评点）
白天        30 min 阅读 + 60 min 手绘
晚上 21:30  上传图纸 → 出六维评分卡 + 致命问题 Top3 + 对标案例
周六 / 周日  全休，不推送、不评价
```

## 训练日怎么数

不看日历算天数，**直接查 `04-训练日历.md` 第五节的逐日表**：今天日期 → 训练日序号 # → 周次 → 周内第几天 → 当天日型。

12 周（60 个训练日）为一个完整周期，结束后进入「第二轮：以自己参与过的真实项目复盘为主」。

## 里程碑自测

- **第 20 个训练日**（约第 4 周末）：能不看资料说出商业平面的 12 个核心指标数字。
- **第 40 个训练日**（约第 8 周末）：能独立读一份陌生商业平面，10 分钟内指出动线、得铺率、后勤三处硬伤。
- **第 60 个训练日**（收官）：独立完成一个 4 万㎡ 地块的商业裙楼总图 + 首层 + 标准层平面，得铺率 ≥55%，指标表自洽。

## 对标 Aedas 的硬门槛（来自其公开招聘要求）

- 经验：助理岗 1 年+，设计师岗 4 年+，主任设计师 9 年+，方向须为综合体 / 商业 / 酒店 / 办公
- 软件：CAD、Photoshop、V-Ray、Revit / BIM、Rhino + Grasshopper
- 学历：研究生及以上（助理岗要求 post-graduate）
- 语言：中英文书面与口语流利
- 作品集：**必须**，且是唯一决定性材料
- 加分项：手绘能力（Aedas 城市设计岗明确写 "Good hand drawing skills is a plus"）
- 注意：Aedas 的主任设计师岗明确要求「综合使用功能、商业设计、设计代码和技术能力」——即**规范与技术能力被写进了晋升标准**，这正是本训练系统第 2、8、9 周要攻的方向。
